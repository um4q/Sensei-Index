Q2 · Lambda tuning (+10% CO at t = 6 min)

Measured values

ReadingValue
Start / final PV30% → ≈ 55%, so ΔPV = 25%
Dead time τd1.5 min (from the CO step at 6 min to where the PV starts to rise, about 7.5 min)
63.2% point30 + 0.632 × 25 = 45.8%, reached at ≈ 9.3 min
Time constant τ19.3 − 7.5 = 1.8 min
Process gain KpΔPV / ΔCO = 25 / 10 = 2.5

a) Transfer function and aggressive control (λ = 1)

Gp(s) = Kp·e^(−τd·s) / (τ1·s + 1) = 2.5 e^(−1.5s) / (1.8s + 1)

Larger of τ1 (1.8) and τd (1.5) = 1.8   →   τc = 1 × 1.8 = 1.8
Kc = τ1 / [Kp(τc + τd)] = 1.8 / [2.5(1.8 + 1.5)] = 1.8 / 8.25 = 0.22
Ti = τ1 = 1.8 min/repeat

b) Conservative control (λ = 3)

τc = 3 × 1.8 = 5.4
Kc = 1.8 / [2.5(5.4 + 1.5)] = 1.8 / 17.25 = 0.10
Ti = τ1 = 1.8 min/repeat
Answer: Gp(s) = 2.5e^(−1.5s)/(1.8s + 1). Aggressive: Kc = 0.22, Ti = 1.8 min. Conservative: Kc = 0.10, Ti = 1.8 min.

The reaction rate R (≈ 9.1 %/min) belongs to the ZN open-loop method. Lambda tuning does not use it.

c) Expected outcome (sketch)

Label both curves. Both stay flat for the 1.5 min dead time. Aggressive rises faster (a small overshoot is possible); conservative is slower with no overshoot. Both settle on SP.

Q3 · ZN open loop / reaction curve (+10% CO at t = 0)

Method and definitions from the coursepack, Section 5.2 (Ziegler–Nichols Open Loop Tuning, Reaction Curve Method).

a) Reaction rate and dead time

Obtain recording and determine LR & L.  ΔCO = +10% (step at t = 0 min)

Draw the tangent line at the inflection point (or steepest slope):
   inflection ≈ 43.5% at ≈ 0.5 min

R = slope of tangent line at inflection point
R = ΔPV / time                  (units %/minute)
  = (50 − 40)% / (1.0 − 0.23) min   ← two points read off the tangent
  ≈ 13 %/min

L = the dead time (time in minutes from step change to intersection of tangent line
    with the original PV of 40%)
  ≈ 0.23 min

RL = R·L (units %) = measurement of the tangent line from the original PV
                     at the time of output change (t = 0)
   = 13 × 0.23 ≈ 3.0%
   check: at t = 0 the tangent is at ≈ 37%, i.e. 40 − 37 = 3.0% below the original PV
Answer: Reaction rate R ≈ 13 %/min, dead time L ≈ 0.23 min (RL ≈ 3.0%).

b) Tuning parameters (Table 3: Open Loop Ziegler–Nichols Reaction Curve)

PID:  Kc = 1.2 ΔCO / (LR) = 1.2 × 10 / 3.0 = 4.0
      Ti = 2L             = 2 × 0.23      = 0.46 min/repeat
      Td = 0.5L           = 0.5 × 0.23    = 0.115 min

Check: Td ≥ 0.1 min, so PID is used.
(Coursepack: "If calculated Td for a PID is less than 0.1 min use a PI controller (re-calculate).")
Rate/Reset = 0.115 / 0.46 = ¼ ✓
Answer: PID with Kc = 4.0, Ti = 0.46 min/repeat, Td = 0.115 min. Then test the response; leave Reset and Rate as calculated and adjust Kc to suit.

Readings come from a photo, so yours may differ slightly. Read R and L from the same tangent line. If your L gives Td under 0.1 min, re-calculate as PI: Kc = 0.9 ΔCO / (LR), Ti = 3.33 L.

Q4 · Checking a student's tuning (Kc 2.1, Ti 0.52, Td 0.13)

Formula from the coursepack, Section 5.3 (Decay Ratio = DR = B/A); measurement done the way the solved sheets do it (Q8, Q9). Answers for b and c use the coursepack's fine-tuning rules (5.3 Step 5 and 5.5 Trial and Error).

a) Decay ratio

Measured: 1st peak ≈ 66.2%, trough after it ≈ 55.6%, 2nd peak ≈ 62.2%

Decay Ratio = DR = B / A
  A = 1st peak − trough       = 66.2 − 55.6 = 10.6
  B = 2nd peak − same trough  = 62.2 − 55.6 = 6.6
  These are half-cycle swings, so square the ratio (as on the solved sheets):
  DR = (B / A)² = (6.6 / 10.6)² = (0.62)² ≈ 0.39

Desired ¼ amplitude decay: DR = 0.25.   0.39 > 0.25 → too oscillatory.
Answer: DR ≈ 0.39, which is more than ¼, so the response is too oscillatory (not stable enough).

b) Kc

Coursepack (5.3 Step 5): "Increasing KC increases the speed of response,
but also makes the loop less stable."
Decrease Kc. Lower Kc gives a more stable loop, so the oscillations die out faster and DR moves down toward ¼.

c) Keeping Kc = 2.1

Coursepack (5.3 Step 5): "Increasing KI (decreasing TI) increases the cyclic
period, but also makes the loop less stable."
Coursepack (5.5): "keep the ratio between reset and rate (reset/rate = ¼) the same."
Current: Td / Ti = 0.13 / 0.52 = ¼
Increase Ti (less integral action, so the loop is more stable) and increase Td by the same proportion, so Td = Ti/4 is kept. For example, Ti 0.52 → 0.70 min/repeat gives Td 0.13 → 0.175 min. Then test again; the coursepack says tune coarse, because fairly large changes are needed to see a difference.
